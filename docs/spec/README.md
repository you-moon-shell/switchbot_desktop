# 仕様（spec）インデックス

SwitchBot デスクトップアプリの仕様置き場。**横断的なアーキテクチャ**と**エピック単位の要件**を分けて管理する。

## アーキテクチャ（横断）

- [バックエンド（Rust コア）](architecture/backend.md)
- [フロントエンド（React / WebView）](architecture/frontend.md)

## エピック

各エピックは `epics/<id>/` 配下に `requirements.md`（→ 必要に応じて `design.md` / `tasks.md`）を置く。

| Epic | 内容 | 状態 | ドキュメント |
| --- | --- | --- | --- |
| **A** | オンボーディング/認証 | 実装済 | [requirements](epics/a-onboarding-auth/requirements.md) |
| **B** | デバイス状態（一覧・状態の読み取り） | 次 | （未作成） |
| **C** | デバイス基本操作（共通 ON/OFF 等） | B の後 | （未作成） |
| **D** | デバイス個別操作（機種別コマンド） | C の後 | （未作成） |
| **E** | シーン（一覧・実行） | D の後 | （未作成） |

着手順とリスク：A（土台）→ **B 読み取り（低リスク）→ C 共通の書き込み → D 機種別 → E シーン** と段階的に増やす。

## Backlog（Epic 化しない＝当面やらない）

センサー可視化 / 自動化 / メニューバー常駐 / 設定画面（資格情報の更新。削除＝ログアウトは A で実装済）/ レート制限の作り込み / `tracing` ログ / 自動更新 / Windows 対応。
